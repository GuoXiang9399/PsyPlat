## 经验教训

- 同一消息里对同一文件发多个并行 Edit 会互相覆盖（部分写入丢失），表现为"返回成功但 grep 仍有残留"。
  多处修改同一文件时应改用脚本一次性替换，或严格串行 Edit。
- 用全局正则替换颜色时，`color:` 会连 CSS 规则里的图标色一起改掉；
  应先精确替换 CSS 声明，再用正则处理内联 style，且用 `(?<![-\w])color:` 避开 border-color/background-color。
